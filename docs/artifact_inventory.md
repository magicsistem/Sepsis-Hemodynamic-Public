# Artifact Inventory

Public inventory files live under `external_artifacts/inventory/`.

## Public Inventory Files

- `artifact_inventory.csv`: compact list of public compact outputs and local-only artifact groups.
- `artifact_inventory.md`: readable summary of inventory categories.
- `checksums.csv`: SHA-256 checksums for public compact outputs.
- `local_only_manifest.csv`: manifest for local-only manuscript and manuscript-asset groups.
- `hpc_artifact_inventory.csv`: compact summary of HPC artifact categories retained outside Git.
- `hpc_artifact_inventory.md`: readable HPC inventory summary.

Detailed local or HPC inventories may be retained outside the public workflow for traceability. They should not be required by README commands or public scripts.
